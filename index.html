Test Automation Lab

One framework, many kinds of testing, built in the open.

REST API, SQL, browser, message queue, logs, service stubs and load, all in one pytest framework running in Docker and CI. The system under test is a small demo service; payments is just its example domain. Everything on this page is produced by the pipeline, not written by hand.

Claims and the proof for each

What I say I can doWhere to check
Design a test strategy, not only write tests docs/test-strategy.md: ranked risks, the level each one is tested at, and what is deliberately not automated.
Test planning with requirement traceability Requirements as GitHub issues with acceptance criteria and risks; every test links to its issue, and the traceability matrix maps risk to requirement to test.
End-to-end frameworks with Pytest, Playwright and page objects tests/ui, tests/pages: page objects with role and test-id locators; test data comes from the API.
Web UI and API test layers tests/api with typed clients in tests/clients and Pydantic response models; tests/ui for the browser.
API contract with OpenAPI (Swagger) tests/utils/openapi.py: every response checked against the service's own OpenAPI document; tests/contract fails on any API change not committed to the pinned document.
BDD scenarios readable by non-engineers (Gherkin) tests/bdd: five business scenarios in Gherkin (refunds, safe retries, a declined card, access between merchants, a refund in the browser) run with pytest-bdd on the same clients, factories and page objects as the other layers.
Postman collections run by Newman postman/: the API smoke as a collection for manual QA and developers, admin one-time code computed in a pre-request script; Newman runs it on every pull request.
UI validated down to fonts and colours tests/ui/test_styles.py: computed styles of key elements compared with the values the stylesheet defines.
Backend failures simulated in the browser tests/ui/test_status_refresh.py: page.route answers with a 500, a slow reply, a dropped connection or made-up data, and the page has to cope.
Wired into CI/CD .github/workflows: every pull request is gated; run history.
Failures diagnosable from the report Nightly Allure report: a failed test carries its steps, last request and response, and SQL; the report keeps the trend.
Fixture-based test data management tests/factories, tests/conftest.py: a fresh merchant per test, created through the API and cleaned up after.
SQL backend verification tests/db: JOIN, GROUP BY / HAVING, CTE and window checks on data the tests created; the SQL is attached to the report.
Logs as test evidence tests/logs: a request's JSON log lines found by its request id, events checked in order, and a scan proving no password, token or one-time code is logged.
RabbitMQ tests/events: each test reads payment events from its own queue and checks the fields, the request id and that nothing is published for a rejected request.
Payments domain (the demo service) tests/api: payment state machine, idempotency keys, partial refunds.
2FA flows with PyOTP tests/ui/test_login.py: admin login with a time-based one-time code.
Flaky-test triage and retry policy Flakiness policy: no global retries, flaky needs a reason, and collection fails without one.
Testing around an external provider tests/integration: decline, 5xx and timeout against WireMock stubs, with the charges checked through its admin API.
Load testing load and the published Locust report: the run fails on p95 over 500 ms or errors over 1 %.
Docker docker-compose.yml: app, database, RabbitMQ and WireMock provider stub with health checks, plus the tests container; multi-stage app/Dockerfile.
GitHub Actions and parallel runs .github/workflows/nightly.yml: the full suite in parallel with pytest-xdist, published as one Allure report with history.
Type hints, ruff, pre-commit .pre-commit-config.yaml and the lint job in .github/workflows/pr.yml: ruff and ruff format on every pull request.
No secrets in a public repository scripts/make_env.sh: credentials are generated per run and masked, so the repository holds no secrets.
